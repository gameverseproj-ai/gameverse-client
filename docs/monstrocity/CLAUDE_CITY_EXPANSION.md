# Claude: полный город city-v2, доступные дома и перебежки жителей

Работай только в be-core. Клиент готовит город и визуальное поведение; не меняй клиент. Не ограничивай новую игру старым courtyard-v1. Не подменяй геометрию существующей версии. Сохрани API и правила времени, идемпотентности и авторитетных snapshots из protocol.md.

Обязательные файлы: city-v2.manifest.json (точная геометрия), city-v2.rules.json (доступные здания, гарантированные тайники и маршруты жителей), MONSTROCITY_DESIGN.md, openapi.json, protocol.md. Манифесты воспроизводятся командой `node scripts/export-monstrocity-city.cjs` в клиентском репозитории.

## Территория

Новая версия карты city-v2: границы [-67,67] по X и Z, 134 × 134 м, девять кварталов, 38 зданий, 49 контейнеров, 10 жителей, 13 кандидатов убежищ. Старый courtyard-v1 остаётся 34 × 34 м. Создай новую configVersion с mapVersion=city-v2. Не перезаписывай monstrocity-v1/v2 и не сбрасывай активные забеги/инвентарь. Bootstrap должен отдавать city-v2 для новых забегов. Для пользователя со старым активным забегом обеспечь явную безопасную миграцию карты с сохранением дней, покупок и неизменённых IDs первого квартала, либо явный выбор продолжить старый / начать новый город. Не сообщай об успешном расширении, пока HTTP sync реально не разрешает движение за x/z=17 и исследование дальних кварталов.

MonstrocityConfigService уже поддерживает resource-location и versioned map resources: используй существующий механизм. Примени лёгкий боевой профиль из CLAUDE_COMBAT_TEST_BALANCE.md к новой конфигурации. Проверь, что snapshot.mapVersion и bootstrap.config.mapVersion согласованы с закреплённым за забегом configVersion.

## Дома и находки — утверждённое правило

Вход разрешён только в 12 зданий с interior=true из manifest. Остальные имеют сплошной collision footprint. У каждого доступного дома северный дверной проём шириной 2 м. Внутри каждого есть свой контейнер; полный список гарантированных IDs — rules.guaranteedContainerIds. Никакой вероятности пустого результата: первый завершённый обыск такого тайника даёт минимум один существующий collectible (еда, вода или меч). Меч сохраняет свою редкость. Не создавать новый тип валюты или предмет без согласования.

Гарантия назначается сервером по манифесту, а не флагом запроса клиента. Повтор поиска, повтор идемпотентного запроса и sync не выдают награду ещё раз. На смерти найденные предметы и знания сбрасываются, купленные сохраняются. Новому забегу доступны новые находки. Правила уличных контейнеров можно оставить прежними. Доступный дом не становится автоматически убежищем: это отдельное свойство забега.

## Жители

Они одиночные NPC, не другие онлайн-игроки. Маршруты из rules.residentRoutes: короткий рывок между from/to, speed=2.8 м/с, пауза waitA/ waitB у концов, индивидуальный offsetSeconds. Базовая позиция с плавным разгоном/торможением:

- travel=distance(from,to)/speed; period=2*travel+waitA+waitB;
- phase=(run.activeElapsedMs/1000+offsetSeconds)%period;
- [0,waitA): from; затем travel секунд from→to; затем waitB секунд to; затем travel секунд to→from;
- линейный progress p преобразуется в p*p*(3-2*p).

Один общий расчёт нужен для nearby.position, проверки дистанции talk и серверного взаимодействия. Нельзя оставить разговор в неподвижном стартовом якоре, пока модель бежит в другом месте. Движение и маршруты не пересекают здания/контейнеры; меню и диалог останавливают время. Клиент использует ту же формулу и всегда принимает позиции из authoritative nearby. Для старых карт оставь совместимость, но также возвращай реальную позицию NPC, когда включено движение. Если вводишь особое поведение при угрозе, передавай его через snapshot, а не скрытую клиентскую симуляцию.

## Проверки при сдаче

Реальный HTTP-сценарий на отдельном anonymous аккаунте/изолированной БД: новый забег city-v2; пройти из центра за границы первого квартала к каждой стороне, обыскать дальний тайник, найти убежище, pause/resume/reconnect без отката позиции. Двери: пройти каждый из 12 входов, проверить стены и закрытые здания. В каждом доме первый поиск гарантирует предмет, второй отклонён; повтор ключа возвращает прежнюю награду без повторного начисления. После смерти купленные предметы сохранены.

NPC: позиции в разные activeElapsedMs, разговор возле фактической движущейся позиции, отклонение разговора издалека, отсутствие движения в паузе и повторного раскрытия убежищ. Для старого courtyard-v1 проверить прежнюю границу и сохранность активных забегов. Предоставь точную configVersion, способ её запуска и результаты реального HTTP-теста.

## Утверждённая длительность суток (24 октября 2026)

В новой серверной configVersion установи phaseSeconds={"day":120,"evening":60,"night":120,"morning":60}. Порядок: день → вечер → ночь → утро. Полный цикл 360 секунд активной игры. Начальный countdown берётся из конфигурации, без константы 240000. survivedDays и пороги сложности, в том числе начало уклонения на 30-м дне, рассчитываются по сумме phaseSeconds. Меню и пауза не расходуют время. Проверь границы 120/180/300/360 секунд и следующий цикл. Не переписывай конфигурацию уже закреплённых старых забегов: новый цикл включается через новую версию/согласованную миграцию.
